# M&A魅力度スコア 再設計案（2026-07-28）

## 現状（問題）
- 計算式: `min(施設数×20 + 従業者数/10, 100)`（`sql_aggregator.rs:2372`）
- 上位100法人が全件100点に張り付き、比較の意味をなさない
- ユーザー方針: ①偏差値は母集団で変動するのでNG（絶対基準にしたい）②加点はM&A/営業で観点が変わる

## 設計方針
1. **単一スコア表示を廃止**し、生値の多軸カラム（施設数・従業者数・都道府県数・違反有無・財務有無）をそのまま出してソートキーをユーザーが選ぶ
2. スコアを残す場合は**絶対しきい値ベース**（母集団非依存の固定基準）にする。例:
   - 規模: 施設数 1-2=小 / 3-9=中 / 10+=大（固定境界）
   - 従業者: 50未満/50-199/200+（固定境界）
   - これらを「バッジ」で表示（点数化しない）
3. **用途別プリセット**を用意（M&A観点 / 営業観点）。同じ生データに対し、並び順と強調カラムだけを切り替える
   - M&A観点: 財務健全性・違反なし・規模を重視
   - 営業観点: 施設数・地域集中・成長性を重視

## 実装の当たり（次のステップ）
- backend `ma_screening` は既に生値（facility_count/total_staff/prefectures/has_violation/has_financials等）を返している → **スコア計算(l.2372)を除去し、フロントで用途別ソート**に寄せるのが最小変更
- フロントに「観点」トグル（M&A/営業）を追加、ソートキーと表示バッジを切替
- スコア列は当面「規模バッジ（小/中/大）」に置換

## 要確認（実装前にユーザー判断）
- 絶対しきい値の具体的な境界値（上記は仮）
- 「営業観点」で重視すべき指標（成長性=事業年数? 地域集中度?）の定義
