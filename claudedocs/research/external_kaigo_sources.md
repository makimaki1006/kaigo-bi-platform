# 介護業界 外部データソース網羅調査

**作成日**: 2026-07-24
**目的**: kaigo-bi プラットフォームのデータ拡充。「介護サービス情報公表システム(kaigokensaku.mhlw.go.jp)」以外の、介護業界に関する公開情報サイト・データソースを網羅的に調査する。
**方法**: WebSearch + WebFetch で各サイトを実地確認。粒度・取得方法・規約・ペルソナ適合を整理。

---

## エグゼクティブサマリ

- 最有望は **WAM NET「社会福祉法人 現況報告書等情報検索/財務諸表等電子開示システム」**。全国の社会福祉法人の現況報告書・財務諸表(貸借対照表/事業活動計算書等)が**法人単位の構造化データ**として公開され、拠点(事業所)一覧・サービス種別まで紐づく。介護業界で唯一「財務」に踏み込める一次ソースであり、経営支援・M&A・営業支援の3ペルソナに直接効く。
- 集計・マクロ指標は **e-Stat(介護給付費等実態統計・介護保険事業状況報告)** と **介護労働安定センター(介護労働実態調査)** で網羅。市区町村×サービス種別の需給・単価・賃金・離職率が取れる。
- 倒産・休廃業などの**経営リスクシグナル**は東京商工リサーチ/帝国データバンクの公表レポート(記事)。数値は使えるが再配布に制約。
- 求人・給与相場・M&A案件は民間サイト(ウェルミージョブ/ジョブメドレー、バトンズ等)のスクレイピングが必要。規約グレー。
- 「介護情報公表システム」自体のオープンデータ版(WAM/自治体)と、その障害福祉版は、政府標準利用規約ベースで**商用利用可**。既存取り込みの補完・位置情報付与に有効。

粒度と規約を一覧化すると、**一次公的ソース(公表可・構造化)を軸に、民間サイトはシグナル補完**という役割分担が妥当。

## 1. WAM NET 社会福祉法人 現況報告書等情報検索 / 財務諸表等電子開示システム ★最有望

- **URL**:
  - 公開検索(一般向け): https://www.wam.go.jp/wamnet/zaihyoukaiji/
  - 財務諸表等電子開示システム(公表): https://www.wam.go.jp/wamnet/zaihyoukaiji/pub/PUB0201000E00.do
  - 連絡板: https://www.wam.go.jp/content/wamnet/pcpub/top/zaihyou/houjin/
- **運営主体**: 独立行政法人福祉医療機構(WAM)。厚労省の社会福祉法人制度に基づく法定の情報開示システム。
- **データの中身と粒度**:
  - **法人単位**で、現況報告書・計算書類(貸借対照表・資金収支計算書・事業活動計算書)・社会福祉充実計画・定款・役員名簿・報酬基準を開示。
  - 法人詳細に「基本情報」「実施サービスの種類」「**事業所(拠点)一覧**」「現況報告書等ダウンロード」「所轄庁」が含まれる → **法人→拠点→サービス種別**の紐付けが可能。
  - 対象は**社会福祉法人**(特養・老健運営主体の中核)。株式会社・医療法人・NPO等の営利/非営利事業者は対象外(=カバレッジの限界)。
- **取得方法と難易度**:
  - 個別法人はWeb検索+**Excel(Zip)/帳票ダウンロード**。CSV一括・公式APIの明示は確認できず。
  - 全法人の網羅取得は検索画面クローリング + 帳票パースが必要 → **難易度: 中〜高**(構造化されている分、財務諸表パースの実装価値は高い)。
- **規約(商用利用・再配布)**: ページ上に商用利用・再配布の明示規約は確認できず。制度趣旨が「国民への説明責任・透明性確保のための公表」であるため閲覧・分析利用は想定内だが、**一括転載・再配布は要確認**(WAMへの照会推奨)。
- **効くペルソナ**: **経営支援◎ / M&A◎ / 営業支援○ / BI閲覧○**。財務健全性スコアリング、赤字法人抽出、M&Aターゲット選定、営業先の財務規模把握に直結。

## 2. 地域包括ケア「見える化」システム

- **URL**: https://mieruka.mhlw.go.jp/
- **運営主体**: 厚生労働省(老健局)。都道府県・市町村の介護保険事業計画策定支援システム。
- **データの中身と粒度**: 認定情報・介護保険レセプト情報を基にした**地域間比較の集計指標**(要介護認定率、給付費、サービス見込み量等)。市区町村・都道府県単位の集計。
- **取得方法と難易度**:
  - 詳細機能は**自治体職員向けアカウント制**(所属のアカウント管理者から発行)。一般の任意登録も一部あるがフルアクセスは行政向け。
  - 公開グラフ・一部データはWeb閲覧、支援情報送付ソフト経由のCSV入出力は自治体業務用。
  - **難易度: 高**(アクセス権限の壁)。一般事業者/BI事業としては公開部分のみ利用可。
- **規約**: 政府システム。公開統計の利用は一般に可だが、システム本体は行政利用前提。
- **効くペルソナ**: **経営支援○ / 営業支援○ / BI閲覧○**。地域の需給ギャップ(供給不足エリア)分析、出店・営業エリア選定の背景データ。

## 3. e-Stat(政府統計) — 介護給付費等実態統計 / 介護保険事業状況報告 / 介護サービス施設・事業所調査 ★公的マクロの主軸

- **URL**:
  - 介護給付費等実態統計: https://www.e-stat.go.jp/stat-search/files?tstat=000001123535
  - 介護保険事業状況報告: https://www.e-stat.go.jp/stat-search/files?toukei=00450351&tstat=000001031648
  - 介護サービス施設・事業所調査: https://www.e-stat.go.jp/stat-search/files?toukei=00450042
- **運営主体**: 厚生労働省(調査元) / 総務省統計局(e-Stat基盤)。
- **データの中身と粒度**:
  - 介護給付費等実態統計: 介護保険総合データベース由来。**サービス種類×要介護度×年齢×月次**の受給者数・費用額。都道府県別あり。
  - 介護保険事業状況報告: 第1号被保険者数・認定者数・給付費を**市区町村/都道府県単位**で月次・年次。
  - 施設・事業所調査: 施設数・定員・利用者数・従事者数の集計。
  - いずれも**集計統計**(個別事業所は不可)。
- **取得方法と難易度**: **CSV/Excel直接DL、e-Stat API(要APIキー・無料)対応**。**難易度: 低**。
- **規約**: 政府統計 → **政府標準利用規約(出典明記で商用利用・再配布可)**。最もクリーンに使える。
- **効くペルソナ**: **BI閲覧◎ / 経営支援◎ / 営業支援○ / M&A○**。市場規模・伸び・地域別需給・単価トレンドのベンチマーク基盤。

## 4. 東京商工リサーチ(TSR) / 帝国データバンク(TDB) — 倒産・休廃業統計 ★リスクシグナル

- **URL(公表レポート例)**:
  - TSR 2025年 介護事業者 休廃業・解散653件: https://www.tsr-net.co.jp/data/detail/1202326_1527.html
  - TSR 2025年 介護事業者 倒産176件(過去最多): https://www.tsr-net.co.jp/data/detail/1202283_1527.html
  - TDB 老人福祉事業者の倒産動向(2025): https://www.tdb.co.jp/report/economic/20260217-welfare-br2025/
- **運営主体**: 民間信用調査会社。
- **データの中身と粒度**:
  - 公表レポートは**全国/業態別(訪問介護・通所・有料老人ホーム・GH等)の集計値**(件数・負債総額・前年比・要因分析)。
  - 個社の倒産・信用情報は**有料の企業データベース(TSR企業情報/TDB COSMOS)**で事業所単位取得可(要契約)。
- **取得方法と難易度**: 公表レポートはWeb記事(手動転記/スクレイピング)。個社データは有料契約。**難易度: 記事=低 / 個社=高(有料)**。
- **規約**: 記事は著作物。**数値の引用は可だが本文転載・再配布・商用二次利用は要許諾**。個社データベースは契約条件に従う。
- **効くペルソナ**: **経営支援◎ / M&A◎ / 営業支援○ / BI閲覧○**。業態別リスク・撤退トレンド、M&Aの売り手増加背景、営業トークの市況根拠。

## 5. 介護労働安定センター — 介護労働実態調査 ★人材・賃金の主軸

- **URL**: https://www.kaigo-center.or.jp/report/jittai/
- **運営主体**: 公益財団法人 介護労働安定センター(厚労省委託の毎年度調査)。
- **データの中身と粒度**: 「事業所調査」+「労働者調査」。**離職率・採用率・賃金・過不足感・雇用形態・就業意識**。全国/一部属性別の集計(個別事業所非公開)。プレスリリースPDF+詳細集計。
- **取得方法と難易度**: PDF/Excel公開。**難易度: 低〜中**(PDFパース)。
- **規約**: 公的調査。出典明記で分析利用可(転載は要確認)。
- **効くペルソナ**: **採用コンサル◎ / 経営支援○ / BI閲覧○**。離職率・賃金相場ベンチマーク、採用提案の根拠データ。

## 6. 介護求人サイト(ウェルミージョブ〈旧カイゴジョブ〉/ ジョブメドレー / カイゴジョブエージェント等) ★採用シグナル

- **URL**:
  - ウェルミージョブ: https://www.kaigojob.com/
  - ジョブメドレー(介護): https://job-medley.com/hh/
  - カイゴジョブエージェント: https://www.kaigoagent.com/
- **運営主体**: 民間(エス・エム・エス〈ジョブメドレー/カイゴジョブ〉等)。
- **データの中身と粒度**: **求人単位**の職種・雇用形態・**給与レンジ・勤務地・事業者名**。実例: カイゴジョブエージェントで介護職求人 約11,577件、時給1,010〜1,100円/月給21〜23万円帯。地域×職種の求人量・給与相場のリアルタイムシグナル。
- **取得方法と難易度**: 公式API/オープンデータなし → **スクレイピング必須**。求人量・給与の時系列化には定期クロール実装。**難易度: 中〜高**。
- **規約**: 各社利用規約で**自動収集を禁止している可能性が高い(要精査)**。商用再配布はほぼ不可。あくまで内部シグナル用途に留めるのが安全。
- **効くペルソナ**: **採用コンサル◎ / 営業支援○ / BI閲覧○**。人手不足の逼迫度(求人倍率代替)、給与相場、採用競合状況。

## 7. 医療介護情報局 caremap.jp(株式会社ケアレビュー) — 民間の公表システム集約 ★実装の近道候補

- **URL**: https://caremap.jp/cities/search/facility_kaigo
- **運営主体**: 株式会社ケアレビュー。
- **データの中身と粒度**: 情報公表システムを基に**事業所単位**で再構成。職員数(看護/介護)・利用者数(要支援・要介護別)等でフィルタ可能。医療(DPC等)も併載。
- **取得方法と難易度**: Web検索は無料。**有料の「データファイル作成サービス」でCSV等の一括取得可**(規模不明)。自前クロールより整形済みデータを買う選択肢。**難易度: 低(有料前提)**。
- **規約**: 商用可否は個別要問い合わせ(有料サービスの契約条件次第)。
- **効くペルソナ**: **営業支援◎ / 経営支援○ / M&A○ / BI閲覧○**。既存の情報公表システム取り込みを補強する整形済みソースとして比較検討価値あり。

## 8. M&A案件プラットフォーム(バトンズ / 日本M&Aセンター 等) ★M&A直結

- **URL**:
  - バトンズ(介護付有料老人ホーム売却案件): https://batonz.jp/sell_cases/bk_1100000/bk_1103005/
  - 日本M&Aセンター(介護・福祉): https://www.nihon-ma.co.jp/sector/care.php
- **運営主体**: 民間M&A仲介/マッチング。
- **データの中身と粒度**: **案件単位**(匿名)。業態(有料/GH/住宅型等)・地域(都道府県レベル)・**売上高帯・譲渡希望額帯**を非会員でも一部閲覧。介護付有料老人ホームで約157件。施設名・詳細所在地・営業利益は**会員登録後**。
- **取得方法と難易度**: 一覧の基本情報はスクレイピング技術的に可、詳細は認証ゲート。**難易度: 中**。
- **規約**: 匿名案件。自動収集の可否は規約要確認。個別詳細は会員限定。
- **効くペルソナ**: **M&A◎ / 経営支援○**。売り案件のボリューム・価格相場・エリア偏在の把握。

## 10. 行政処分・指導公表(厚生局 / 都道府県 / 民間アーカイブ) ★コンプラ/リスク

- **URL**:
  - 民間アーカイブ「介護施設 行政処分データベース」: https://kaigo-record.jp/kaigo-archive-portal/
  - 各都道府県・地方厚生局が指定取消/効力停止/指導事案をWeb公表(自治体ごとに散在)
- **運営主体**: 各自治体・地方厚生局(一次) / 民間サイト(集約・二次)。
- **データの中身と粒度**: **事業所単位**の処分名・処分日・理由(不正請求等)。自治体ごとにPDF/HTMLで様式バラバラ。民間アーカイブが横断集約している。
- **取得方法と難易度**: 一次は自治体ごとのスクレイピング(様式不統一で**難易度: 高**)。民間集約サイトを起点にするのが現実的。
- **規約**: 一次公表は行政情報。民間アーカイブは各サイト規約要確認。
- **効くペルソナ**: **経営支援○ / M&A◎(デューデリジェンスのレッドフラグ) / 営業支援○(与信) / BI閲覧○**。

## 11. 処遇改善加算の取得状況(参考: 事業所別公表は限定的)

- **URL**: https://www.mhlw.go.jp/shogu-kaizen/index.html (制度・様式) / 集計は各種検討会資料PDF・e-Stat。
- **状況**: **事業所別の取得状況を横断で一括公表する公式データは確認できず**。加算区分(Ⅰ〜Ⅴ)や算定率は情報公表システムの各事業所詳細や、厚労省検討会の**集計値**として取得可。個別事業所の加算取得有無は情報公表システム側で拾うのが現実的。
- **効くペルソナ**: 経営支援(加算取得率=経営巧拙の代理指標)、採用コンサル(処遇水準)。

## 実装優先度の提言

1. **即着手(低リスク・高効用)**: e-Stat(#3)と情報公表オープンデータ/障害福祉版(#9)。政府標準利用規約でクリーン、CSV/APIで機械取得可。マクロ市場指標と事業所マスタ(位置情報付き)の土台を固める。
2. **差別化の核(要投資)**: WAM NET財務諸表(#1)。他BIが持ちにくい**法人財務**を構造化できれば、経営支援・M&A・営業支援で強い差別化。帳票パースの実装コストとWAMへの利用照会が前提。
3. **シグナル層**: 介護労働実態調査(#5)・TSR/TDB(#4)・行政処分(#10)。集計/記事ベースで手動更新でも価値。ダッシュボードの「市況・リスク」パネルに。
4. **要規約精査(慎重)**: 求人サイト(#6)・M&A案件(#8)・caremap有料(#7)。スクレイピング規約と商用可否を法務確認してから。まずは内部シグナル用途に限定。
