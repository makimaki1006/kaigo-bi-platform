# kaigo-bi 競合分析（介護業界向けBI/データSaaS）

作成日: 2026-07-24 / 調査手法: WebSearch + WebFetch による実サイト確認

## 対象サービス（kaigo-bi）の前提

介護業界向けBI/データSaaS。5ペルソナ（①BI閲覧 ②経営支援 ③採用コンサル ④営業支援 ⑤M&A）向け。価格 Free〜49,800円/月。

---

## カテゴリ1: 介護経営支援 統合SaaS（最大の間接競合）

### 1-1. カイポケ（エス・エム・エス）
- **URL**: https://ads.kaipoke.biz/ / M&A: https://ma.kaipoke.biz/
- **ターゲット / 価格**: 介護・看護・障害福祉事業者。初期費用ゼロ+月額定額（人数・端末無制限）、2ヶ月無料体験。導入60,000事業所以上（2026年4月時点）。
- **データソース（推定）**: 自社SaaS内の記録・請求(レセプト)データが主。事業者が入力した実績が蓄積される（一次データを自社で保有）。マネーフォワードと提携し会計・人事労務を統合。ウェルモとも提携。
- **kaigo-biに無い機能・データ**: 記録・請求業務そのもの（基幹業務システム）、ファクタリング(早期入金)、会計・給与連携、M&A仲介まで一気通貫。事業者の内部一次データを大量保有。
- **kaigo-biが勝てるポイント**: カイポケはあくまで自社ユーザー(契約事業所)の内部データが中心で、**業界横断・地域横断の外部市場分析**は本質的に弱い。kaigo-biは公開データ(介護サービス情報公表・WAMNET・厚労省経営情報DB等)を横串で分析でき、非カイポケ事業所も対象にできる。価格の入口がFreeで、基幹システム乗り換え不要の軽量BIとして併用されうる。

### 1-2. ミルモシリーズ / ミルモネット（ウェルモ）
- **URL**: https://welmo.co.jp/service/
- **ターゲット / データ**: 在宅介護。ミルモネットは26,100事業所が使う「地域資源情報」集約プラットフォーム。他にAI帳票、音声記録、ケアプラン作成AI等7製品。
- **データソース（推定）**: 地域の介護資源情報（事業所・サービス情報）を集約。現場業務効率化(AI/ICT)寄り。
- **kaigo-biに無い機能**: ケアマネ向けの地域資源検索、ケアプラン作成AI、音声記録DX。
- **kaigo-biが勝てるポイント**: ミルモは「現場業務支援」が主で、**経営者・営業・M&A向けの意思決定BI**という切り口ではない。kaigo-biの経営/営業/M&Aペルソナ設計は棲み分け可能。

## カテゴリ2: 施設DB・地域分析BI（最も直接的な競合）

### 2-1. 福祉施設・高齢者住宅 Data Base BI
- **URL**: https://koureisha-jutaku-db.com/bitool
- **ターゲット**: メーカー営業、コンサル・不動産、自治体、金融機関、老人ホーム運営者。
- **価格（年額・税抜）**: Market Analyze BI 2nd 80,000円 / 地域包括ケア版 264,000円 / Service Analyze BI 2nd 124,800円。12ヶ月契約、年2回データ更新(2月・8月)。
- **データソース**: 自社保有の高齢者施設DB約6万件、要介護者数、全国地方厚生局公開情報、入居率推移。
- **kaigo-biに無い機能・データ**: 施設約6万件+入居率推移という独自蓄積データ。営業・不動産・金融向けの実績。
- **kaigo-biが勝てるポイント**: **更新が年2回と遅い**（kaigo-biはより高頻度更新で差別化可）。価格は年8万〜26万で入口が高く、Freeプランがない。UI/UXが古い懸念。介護以外の切り口（採用・M&A）は非対応。

### 2-2. MarketAnalyzer™ 介護分析版（技研商事インターナショナル）
- **URL**: https://www.giken.co.jp/products/marketanalyzer/nursingcare/
- **ターゲット / 用途**: 施設の新規開設前の商圏分析、開設後の集客最適化。GIS(地図)ベース。
- **データソース（推定）**: 人口統計(年齢・世帯構成)、要介護認定者数、既存事業所立地。汎用GISエンジンの介護特化パッケージ。
- **kaigo-biに無い機能**: 商圏シミュレーション、地図上の充足率可視化という高度なGIS。
- **kaigo-biが勝てるポイント**: MarketAnalyzerはGISツールとして高価・専門的で、価格非公開＝エンタープライズ営業型。kaigo-biは**Web完結・Free入口・軽量BI**として中小事業者に届けられる。採用・M&Aペルソナは非対応。

## カテゴリ3: 営業リスト・法人名簿（データ販売型）

### 3-1. 名簿エンジン / リスト王国 等
- **URL**: https://meibo-engine.com/list/kaigo / https://listshop.biz/column/kaigo.html
- **価格**: 概要版名簿 68,000円 / 詳細版 76,000円 / サ高住 45,000円 / 社会福祉法人 45,000円。オプション(メール・FAX付加)各17,000円。CSV納品。
- **データソース**: 介護サービス情報公表システム・WAMNET等の公開情報をWebスクレイピングで収集・整形。
- **kaigo-biに無い機能**: 完成済みCSVを買い切りで即納。
- **kaigo-biが勝てるポイント**: これらは**静的なCSV売り切り**で分析機能・更新性ゼロ。kaigo-biは同じ公開データを「常時更新+分析+営業支援ワークフロー」まで提供でき、SaaSとしてLTVが高い。営業支援ペルソナはこの層を丸ごと置換しうる。

## カテゴリ4: 介護M&A仲介（データを武器にする仲介業）

### 4-1. ブティックス（CareTEX主催 / M&A支援センター）
- **URL**: https://btix.jp/business/manda.html / https://btix-ma.com/ / https://kaigo-ma.com/
- **ビジネス**: 介護(2015〜)・医療・障害福祉・保育・建設に特化したM&A仲介。介護最大級の展示会CareTEX主催、来場者DBを譲受候補プールに活用。
- **データソース（推定）**: 展示会来場者DB、自社案件DB、介護用品EC顧客基盤。
- **kaigo-biに無い機能**: 実際のM&A成約実行、譲受候補ネットワーク。
- **kaigo-biが勝てるポイント**: ブティックスは「仲介成約」がゴールで、**売り手/買い手の事前スクリーニングや地域の売却候補の定量発掘**はデータ提供として売っていない。kaigo-biのM&Aペルソナは「候補発掘・簡易バリュエーション・地域需給の裏付け」というデータ前工程で差別化・協業しうる。

### 4-2. カイポケM&A / CBパートナーズ / セカンドラボ 等
- **URL**: https://ma.kaipoke.biz/ / https://www.cb-p.co.jp/ / https://2ndlabo.com/
- 介護特化M&A仲介の比較記事・事例が多数。いずれも仲介手数料モデル。
- **kaigo-biが勝てるポイント**: 同上。仲介各社は成約課金で、平時から使うデータSaaSではない。kaigo-biはM&A前の情報収集ツールというニッチを取れる。

## カテゴリ5: 公共・無料の地域分析データ（競合であり供給源）

### 5-1. JMAP 地域医療情報システム（日本医師会）
- **URL**: https://jmap.jp/
- 全国の医療・介護提供体制を地図・地域統計で無料公開。将来の需給を考える参照ツール。
- **kaigo-biへの示唆**: 無料で見られる分、「無料で足りる」と思わせるアンカー。ただしJMAPは**閲覧特化で経営/営業/M&A向けのアクション機能なし**。kaigo-biはJMAPの粒度を超えた事業者単位・実務ワークフローで差別化する必要がある。

### 5-2. 地域包括ケア「見える化」システム（厚労省）
- **URL**: 太子町の活用例 https://www.town.taishi.osaka.jp/... 経由
- 給付月額を全国平均・他自治体と比較できる公的分析システム。主対象は自治体。
- **kaigo-biが勝てるポイント**: 公的システムはUIが硬く自治体向け。民間事業者の意思決定用途では使いにくい。

### 5-3. 厚労省 介護サービス事業者 経営情報データベースシステム
- **URL**: https://www.mhlw.go.jp/stf/tyousa-bunseki.html
- **重要**: 2025年1月から経営情報の報告が義務化。事業者の**財務(損益)データが行政に集約**され、今後匿名化・集計データが公開・分析提供される見込み。
- **kaigo-biへの示唆（両刃）**: これは競合ではなく**新たなデータ供給源**。kaigo-biが早期にこの経営情報を取り込めば、従来「入居率・立地」止まりだった競合(2-1, 2-2)に対し「**実財務ベースのベンチマーク**」という強い差別化データを持てる。逆に厚労省が高機能な分析UIを無料提供すると脅威にもなる。

## カテゴリ6: 介護人材・採用データ

- 有効求人倍率等は厚労省・マイナビ・各媒体が無料公開（介護4.10倍、21都道府県で5倍超）。
- **kaigo-biが勝てるポイント**: 採用コンサルペルソナ向けに、公開求人倍率+地域需給+事業所データを掛け合わせた「採用難易度マップ」等の複合分析は既存の無料統計にはない付加価値。単一指標の再掲では差別化不可。

---

## kaigo-bi の差別化戦略への示唆（5点）

1. **横串の「外部×多目的」がkaigo-biの核**。カイポケ/ミルモは自社ユーザー内部データ、名簿業者は静的CSV、施設DB-BIは年2回更新。kaigo-biは公開データを高頻度更新し、経営・営業・採用・M&Aを1つのデータ基盤で横断できる点が唯一性。
2. **2025年義務化の「経営情報DB」を最速で取り込む**。実財務ベースのベンチマークは競合の「立地・入居率」を超える決定的差別化データになる（ただし厚労省の公式分析UI提供が最大の中長期リスク）。
3. **価格の入口=Freeを武器に中小零細を面で取る**。競合は年8万〜26万・エンプラ営業型が多くFreeがない。Freeで裾野を取り経営/M&Aで課金する二層構造が有効。
4. **「閲覧」で終わらせずアクションに繋ぐ**。JMAP・見える化システムという強力な無料閲覧ツールが存在するため、kaigo-biは営業リスト化・候補発掘・簡易バリュエーション等の「次の一手」ワークフローで差別化しないと無料に負ける。
5. **競合との協業余地**。M&A仲介(ブティックス等)・営業リスト業者は成約/売り切りモデルで平時のデータSaaSを持たない。kaigo-biは彼らへのデータ供給・前工程ツールとして補完関係を築ける。
