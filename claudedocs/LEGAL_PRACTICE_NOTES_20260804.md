# 法務文書の実務的な作り方（2026-08-04 調査）

「規約を出すたびに弁護士へ確認しているとは思えない。別の確認方法やナレッジがあるはず」
という指摘を受けて調べた結果。

**結論: そのとおりで、実務は「全文を弁護士に書かせる」のではなく
「公的な一次情報＋弁護士監修のジェネレータで作り、争点になる条項だけ個別に見てもらう」
という分業が定着している。**

---

## 1. 何を根拠に書けばよいか（一次情報）

規約の中身は、法律とその公的な解説から機械的に決まる部分が大きい。
以下は無料で参照できる一次情報。**まずここに当たるのが実務の基本。**

| 出典 | 何が分かるか |
|---|---|
| [消費者庁 特定商取引法ガイド](https://www.no-trouble.caa.go.jp/what/mailorder/) | 通信販売の表示義務。何を書けば足りるかが条文単位で書かれている |
| [消費者庁 通信販売広告Q&A](https://www.no-trouble.caa.go.jp/qa/advertising.html) | **住所・電話番号の省略条件、バーチャルオフィス可否の公式見解**。今回の論点はここで解決した |
| [経産省 電子商取引及び情報財取引等に関する準則](https://www.meti.go.jp/policy/it_policy/ec/) | 利用規約が契約に組み入れられる条件、変更が有効になる条件、無効になる条項の類型。2025年2月改訂 |
| 個人情報保護委員会 ガイドライン | プライバシーポリシーの必要記載事項、越境移転の説明義務 |

準則は「どう書けば有効か」ではなく**「どういう書き方だと無効になるか」**が判例ベースで
整理されているので、自作の規約を点検する用途に向く。

---

## 2. 弁護士監修のジェネレータ（実務の主流）

スタートアップ・個人開発では、弁護士監修のジェネレータで初版を作るのが一般的になっている。

### KIYAC（キヤク）

弁護士実務経験者が代表を務めるサービス。質問に答えると法律文書が生成される。

| 項目 | 内容 |
|---|---|
| 料金 | 無料プランはプライバシーポリシーのみ。Standard **年額 5,940円（税込）** |
| Standard で生成できるもの | プライバシーポリシー、利用規約、**特定商取引法に基づく表示**、返金ポリシー等 |
| 雛形数 | 100種類以上 |
| 追加 | 生成後に弁護士のリーガルチェックを別途依頼できる |

- [KIYAC の使い方](https://iwb.jp/kiyac-automatically-generate-legal-documents-in-minutes/)
- [KIYAC Blog: 利用規約 雛形の作り方](https://blog.kiyac.app/termsofservice/)
- [個人開発の利用規約・プライバシーポリシーの作り方](https://peaky.co.jp/individual-dev-terms-privacy-policy/)

### 費用の相場感

| 手段 | 費用 |
|---|---|
| ジェネレータ | 年額 6,000円程度 |
| [規約作成代行（IT契約書作成のミカタ）](https://itmikata.tokyo/archives/660) | 99,000円 |
| 弁護士に個別作成を依頼 | 上記より高額 |

**「毎回弁護士」ではなく、金額と論点の重さで手段を選ぶのが実態。**

## 3. 個人事業主の住所公開問題 — 公式見解で解決した

今回いちばん重い論点だったが、**消費者庁が明示的に回答している**。

### バーチャルオフィスの住所・電話番号を使える条件（Q18）

次の3つを満たせば表示義務を果たしたことになる。

1. **取引の場の要件** — プラットフォーム事業者の住所を使う場合は、その取引が
   当該プラットフォーム上で行われていること
2. **連絡先機能の要件** — 連絡先として機能することについて、個人事業者と
   バーチャルオフィス運営事業者との間で**合意がある**こと
3. **情報把握の要件** — 運営事業者が個人事業者の**現住所と本人名義の電話番号を把握**しており、
   確実に連絡が取れる状態であること

> つまり「住所だけ借りる」タイプでは足りず、**連絡先として機能する契約になっているか**が分かれ目。
> 契約前にバーチャルオフィス側へ「特商法の表記に使えるか」を確認するのが確実。

### そもそも省略できる場合（Q15・Q17）

**消費者からの請求があれば遅滞なく書面・メールで提供する旨を広告に表示し、
実際にその体制を整えていれば、住所・電話番号の表示自体を省略できる。**

「遅滞なく」= 申込みの意思決定に先立って十分な時間的余裕をもって提供されること。

> 実装済みの `/legal` は電話番号欄にこの運用の文言を入れてある。
> ただし**省略するなら「請求があれば提供する」旨を明示する必要がある**ので、
> この方式を採るなら文面の調整が要る。

### 使えないもの

**郵便私書箱（POボックス）は住所の要件を満たさない。**

## 4. 弁護士に見てもらう価値があるのはどこか

全文ではなく、**争点になりうる条項に絞る**のが費用対効果が高い。
kaigo-bi の場合は次の4点。

| 条項 | 何が問題になりうるか |
|---|---|
| 賠償上限（利用料12か月分） | 消費者契約法8条・9条。上限を設ける条項自体が無効とされる類型がある |
| 返金しない旨 | 同上。「一切返金しない」は無効となりやすく、当社起因の場合の例外を残す設計が要る |
| 専属的合意管轄 | 相手が消費者だと消費者契約法10条で無効となりうる |
| データの再配布禁止 | 元データが公表情報のため、どこまで制限が及ぶか |

**BtoB前提なら消費者契約法は適用されない**が、顧客に個人事業主が含まれるなら
「消費者に該当する場合はこの限りでない」といった但し書きの要否が論点になる。

[SaaS利用規約の必須条項チェック10項目](https://law-bright.com/corporationlaw/articles/keiyaku-saas-kiyaku-10check/) には、
BtoB SaaS は消費者契約法の適用外だが**民法548条の2（定型約款）の不当条項規制**には
服する旨が整理されている。

## 5. 現実的な進め方（提案）

```
① 公的一次情報で骨格を決める          ← 済（消費者庁Q&A・経産省準則）
   ↓
② ジェネレータで別案を作り突き合わせる  ← 年6,000円。抜け漏れの検出に使う
   ↓
③ 争点4条項だけ弁護士に見てもらう      ← スポット相談で足りる可能性
   ↓
④ 住所方式を決める                    ← バーチャルオフィス or 請求時開示
```

②は「作り直す」のではなく、**すでに実装済みの3ページと突き合わせて
条項の抜けを探す**目的で使うのが効率的。

③は法テラスや自治体の無料法律相談、あるいは
スタートアップ支援の顧問弁護士のスポット相談で足りる範囲かもしれない。

---

## 6. 今回この調査で分かった、実装への反映事項

| 事項 | 現状の実装 | 対応 |
|---|---|---|
| バーチャルオフィスは条件付きで可 | 未反映 | 住所方式が決まり次第 `legal.ts` に反映 |
| 住所・電話番号は請求時開示で省略可 | 電話番号欄に文言あり | 省略方式を採るなら「請求があれば遅滞なく提供」の明示が必要 |
| 私書箱は不可 | — | 選択肢から除外 |
| 定型約款の不当条項規制（民法548条の2） | 未検討 | BtoBでも適用される。賠償上限条項の見直し余地 |
