# kaigo-bi SEO公開コピー 承認チェック

作成日: 2026-07-29

## 現在の状態

公開ページのデザインと未ログイン閲覧は有効だが、コピーは未承認ドラフトとして扱う。

`NEXT_PUBLIC_SEO_CONTENT_APPROVED`が厳密に`true`でない限り:

- 商品紹介ページは`noindex, nofollow`
- sitemapへ商品紹介URLを掲載しない
- ログイン前の人間はページを閲覧可能
- ログイン後ページとデータAPIの保護には影響しない

## 承認手順

1. 上記の各項目について、公開可／修正／非公開を決める
2. 公開ページの文面を修正する
3. 価格・件数・機能を実装と照合する
4. 全公開ページを目視確認する
5. `NEXT_PUBLIC_SEO_CONTENT_APPROVED=true`をビルド環境へ設定する
6. 再ビルド・デプロイする
7. 次の検査を実行する

```powershell
$env:SEO_BASE_URL="https://kaigo-bi.onrender.com"
$env:SEO_EXPECT_INDEX="true"
npm run verify:seo-boundary
```

8. Search Consoleへsitemapを送信する

この承認フラグを、単なるデザイン確認やビルド成功だけでtrueにしてはならない。
