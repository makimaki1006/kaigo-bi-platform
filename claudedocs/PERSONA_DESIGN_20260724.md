# ペルソナ駆動の機能集約設計 (2026-07-24 起案)

## 5つのペルソナと「そのツールとして成立する条件」

### P1. 情報可視化BI(業界を俯瞰したい人 — 全ペルソナの入口)
- **既存資産**: ダッシュボード / 市場構造 / トレンド / インサイト
- **成立条件**: ✅ ほぼ成立済み(全国223,103施設+外部統計)
- **不足**: 特になし。Freeの見せ場として磨く

### P2. 経営支援(介護事業者の経営者・管理者)
- **既存資産**: ベンチマーク / 人材分析 / 賃金分析 / 収益構造 / 経営品質 / コスト推定
- **成立条件**: ❌ **「自施設」の概念が無い** — 今は全国データを眺めるだけで「うちはどうなのか」に答えられない
- **必要な集約**:
  - **マイ施設登録**(事業所番号で自施設を紐付け) → 全ページが「自施設 vs 地域・同サービス平均」で自動比較表示
  - 経営ホーム: 自施設の離職率/賃金水準/加算取得/品質スコアの位置づけを1画面に
  - 施設ヘルスチェック(現admin専用)を「自施設ヘルスチェック」として顧客向けに転用

### P3. 採用コンサルティング(P2と近いが「採る」に特化)
- **既存資産**: 採用天気予報 / 賃金分析 / 人材分析 / 外部統計(求人倍率・人口動態)
- **成立条件**: △ 部品はあるが「この地域でこの職種を採るには」に1画面で答えられない
- **必要な集約**:
  - 採用ホーム: 市区町村×職種の採用難易度 + 適正募集給与(地域の賃金分布から) + 競合施設の処遇改善加算状況
  - 賃金分析に「募集給与シミュレータ」(地域中央値±で採用競争力を判定)

### P4. 営業支援(介護業界に営業する企業)
- **既存資産**: 施設マスタ / リスト生成 / CSVエクスポート(クレジット制)
- **成立条件**: △ リストは作れるが「営業運用」の機能が無い
- **必要な集約**:
  - 検索条件の保存・再実行(「先月の条件で差分だけ」への布石)
  - **除外リスト突合**(自社の既存顧客CSVをアップロード→電話番号で除外してDL) ← Salesforce_List運用の実証済みニーズ
  - 新規開設・情報更新のアラート(データ更新サイクルと連動)
  - リスト項目に決算有無・財務規模を追加(財務スケール化後)

### P5. M&A(仲介・買い手・PEファンド)
- **既存資産**: M&Aスクリーニング / DD支援 / PMIシナジー / 法人詳細 / 財務サマリー(パイロット52件)
- **成立条件**: △ 骨格は完成、**財務データの網羅性が生命線**
- **必要な集約**:
  - スクリーニングに財務フィルタ(債務超過 / 営業赤字 / 人件費率>X% / 売上規模)
  - ウォッチリスト(気になる法人を保存、変化があれば通知)
  - 法人詳細に「後継者リスク推定」(代表者名の変化・設立年数等の代理指標)

## 設計方針: 「ワークスペース(ホーム)」方式

フラットな24タブを廃し、**ペルソナ=ワークスペース**として再構成する:

1. **サインアップ時に利用目的を選択**(業界を知りたい/自施設の経営改善/採用支援/営業リスト/M&A) → 初期表示ワークスペースとおすすめプランを出し分け
2. 各ワークスペースに**ホームページ**(そのペルソナのKPIと主要導線を1画面集約)を新設: 経営ホーム / 採用ホーム / 営業ホーム / M&Aホーム(BIは現ダッシュボードがホーム)
3. サイドバーは「選択中ワークスペースのページ+共通BI」だけを表示し、ヘッダーで切替(全ページは残す。見せ方の集約であり機能削除はしない)

### プラン対応(現行4プランのまま)
| ワークスペース | 対応プラン |
|---|---|
| BI閲覧 | Free(全国のみ)/ Standard |
| 経営支援・採用コンサル | Standard |
| 営業支援 | Pro |
| M&A | M&A |

## 実装ロードマップ(バックログ3件を並走)

| スプリント | ペルソナ側(UI/機能) | データ側(並走) |
|---|---|---|
| S1 | ワークスペース切替+目的選択オンボーディング+経営ホーム(マイ施設登録込み) | **スクレイピング改修設計・実行開始**(財務URL 18万件+鮮度更新。実行は数日がかり) |
| S2 | 営業ホーム(条件保存+除外リスト突合) | 財務抽出スケール化(Claude APIパイプライン) |
| S3 | M&Aホーム(財務フィルタ+ウォッチリスト)、採用ホーム | Resendドメイン認証+Stripe本番化 → **課金開始** |
